# 应收账龄系统（Flask + SQLite）

上传发票与收付款流水，按（UTC 生效时刻， 唯一编号）入账，支持迟到补登的
整批校验与拒收，并按截止日输出应收账龄。

## 功能

- **期初导入（空账一次性）**：选 UTC 期初日，上传发票 / 收款 / 可撤核销三份 CSV，
  三份表与期初日同一事务入账，**有错整批拒收**。
  - 发票：单号、开票日、到期日、原金额、未核销额；开票日不得晚于期初日。
  - 收款：编号、可用额；**只带入仍有可用额或仍可撤销核销的收款**。
  - 核销：编号、收款编号、发票单号、可撤额；两端须在本批。
  - 金额为整数分；**仅未核销额与可用额可为 0**。
  - 每张发票：未核销额 + 关联核销可撤额之和 ≤ 原金额。
  - 期初流水统一记在期初日 00:00:00 UTC，**自期初日零点起即可引用原单号**
    办理核销、冲正或撤销。
  - 开账后，流水生效日与账龄截止日都不得早于期初日。
  - 流水 / 收款 / 发票页对期初项标注「期初」；「期初核销明细」页可查看
    每笔期初核销的仍可撤销额。单独撤销已结清发票上的期初核销后，账龄页
    立即显示该发票恢复的余额，原收款也恢复相应可用额。
- **发票上传**：CSV（单号、开票日、到期日、金额），金额为正整数分。
- **流水分批上传**：收款 / 核销 / 撤销核销 / 银行冲正。每笔含全局唯一编号、
  UTC 生效时刻、正整数分金额。
  - 核销关联收款与发票；撤销核销引用原核销；冲正引用原收款；原单须已生效。
  - 每笔入账后：发票未核销额 ≥ 0、收款可用额 ≥ 0、原核销可撤额 ≥ 0。
  - **补登检查**：新流水与库中旧流水按（生效时刻， 编号）合并重放，任一约束
    被破坏即报**首笔违规记录**并**整批拒收**（事务回滚，原账照常可查）。
- **账龄页**：按截止日列出当天结束时的未结发票、未核销余额、逾期天数与
  账龄段汇总。查询只读 `invoice_daily_delta` 日汇总表，**不重读逐笔流水**。

## 运行

### Docker Compose（推荐）

```bash
docker compose up --build
# 打开 http://localhost:8000
```

SQLite 数据落在命名卷 `ledger-data`（容器内 `/data/ledger.db`）。

### 本地

```bash
pip install -r requirements.txt
python run.py            # http://localhost:8000
```

## 测试

```bash
pytest -q
```

覆盖：迟到冲正（合法/违规两路）、撤销超额、补登核销超额、重复编号、
原单未生效、整批原子性、账龄截止日与逾期天数、Web 上传全流程，
以及期初导入（三表 + 期初日原子入账、各类校验、开账下限、
撤销结清发票期初核销后的账龄与收款恢复、流水页期初标注）。

## CSV 格式

期初发票（表头中英文皆可）：

```csv
invoice_id,invoice_date,due_date,amount_cents,outstanding_cents
INV-001,2026-01-05,2026-02-04,100000,40000
```

期初收款 / 期初核销：

```csv
receipt_id,amount_cents
R-001,60000
```
```csv
allocation_id,receipt_id,invoice_id,revocable_cents
A-001,R-001,INV-001,10000
```

发票（表头中英文皆可）：

```csv
invoice_id,invoice_date,due_date,amount_cents
INV-001,2026-01-05,2026-02-04,100000
```

流水：

```csv
txn_id,txn_type,effective_at,amount_cents,receipt_id,invoice_id,allocation_id
R-001,receipt,2026-01-10T09:00:00Z,80000,,,
A-001,allocation,2026-01-11T10:00:00Z,60000,R-001,INV-001,
U-001,unallocation,2026-01-12T10:00:00Z,20000,,,A-001
V-001,reversal,2026-01-13T10:00:00Z,10000,R-001,,
```

类型也可用中文：收款 / 核销 / 撤销核销 / 冲正。时刻支持 ISO-8601，
无时区按 UTC 处理，内部一律归一到 UTC。

## 设计说明

- 入账校验按实体（收款 / 核销 / 发票）重放其相关流水：全局（时刻， 编号）
  序在单实体上的投影与该实体的余额变化一一对应，因此逐实体检查等价于
  全序逐笔检查。
- 账龄所需余额 = 发票额 − Σ(截止日及以前的日增量)，增量在入账提交时维护，
  因此补登历史流水只需在历史日期写入增量，账龄查询无需重放流水。
- 期初语义：期初发票的「未核销额」与期初收款的「可用额」已是期初时点余额，
  期初核销已含在其中，故不作为后续重放中的扣减事件；撤销期初核销时，
  撤销流水在生效日写入正向增量，从而恢复发票余额与收款可用额。
  期初日存于 `ledger_meta`，作为开账后流水生效日与账龄截止日的下限。
